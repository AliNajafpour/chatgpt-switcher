# Codex Account Switcher

[English documentation](README.md) · نسخهٔ ۱.۴.۰ · ویندوز

این ابزار محلی، برنامهٔ رسمی Codex را با پروفایل‌های جداگانه اجرا می‌کند. برای حساب کاری، شخصی یا حساب‌های دیگر یک پروفایل بسازید، داخل برنامه وارد حساب شوید و دفعه‌های بعد آن را از فهرست حساب‌ها، میان‌بر دسکتاپ یا آیکون کنار ساعت باز کنید.

ورود فعلی شما با عنوان **Main (existing login)** در دسترس می‌ماند. هر پروفایل جدید، داده‌های برنامه و `CODEX_HOME` جداگانه دارد. اجرای هم‌زمان پروفایل‌ها به سازگاری نسخهٔ نصب‌شدهٔ برنامه وابسته است.

این پروژه غیررسمی است و وابستگی سازمانی به OpenAI ندارد. ابزار، حساب یا اشتراک ایجاد نمی‌کند و محدودیت‌های سرویس را تغییر نمی‌دهد.

## دانلود و نصب

به ویندوز ۱۰ یا ۱۱، Windows PowerShell 5.1 یا جدیدتر و برنامهٔ رسمی Codex نیاز دارید. وابستگی اضافه یا مرحلهٔ build وجود ندارد.

۱. [فایل ZIP را دانلود کنید](https://github.com/AliNajafpour/chatgpt-switcher/archive/refs/heads/main.zip).

۲. آن را در پوشه‌ای ثابت، مثلاً `Documents\Codex Account Switcher`، از حالت فشرده خارج کنید.

۳. فایل‌های `ChatGPT-Switcher.cmd` و `ChatGPT-Switcher.ps1` را کنار هم نگه دارید و روی فایل `.cmd` دوبار کلیک کنید.

نام فایل‌ها برای سازگاری حفظ شده است؛ نام نمایشی ابزار Codex Account Switcher است. نصب‌کنندهٔ `.exe` یا اسکریپت نصب آنلاین وجود ندارد.

اگر از Git استفاده می‌کنید:

```powershell
git clone https://github.com/AliNajafpour/chatgpt-switcher.git
cd chatgpt-switcher
.\ChatGPT-Switcher.cmd
```

## ساخت و استفاده از حساب‌ها

۱. گزینهٔ **Add account** را بزنید و نامی مثل `Work` وارد کنید.

۲. پروفایل جدید را باز کنید و داخل برنامهٔ رسمی وارد حساب شوید.

۳. برای حساب بعدی، پروفایل دیگری بسازید و ورود را در همان پروفایل انجام دهید.

۴. برای استفاده از ورود قبلی برنامه، **Main (existing login)** را انتخاب کنید.

ساخت پروفایل، حساب آنلاین نمی‌سازد و ورود Main را کپی نمی‌کند. برای به‌روزرسانی فهرست و نشانگر اجرای حساب‌ها، **Refresh** یا **F5** را بزنید. فهرست‌های بلند داخل پنجره اسکرول می‌شوند.

با راست‌کلیک روی یک پروفایل می‌توانید نام نمایشی را عوض کنید، میان‌بر دسکتاپ بسازید، آن را با حفظ داده از فهرست بردارید یا داده‌های محلی آن را برای همیشه حذف کنید. برای حذف، ابتدا پنجره‌های آن پروفایل را ببندید. حذف دائمی در رابط گرافیکی تأیید می‌خواهد.

## میان‌بر منوی Start و آیکون کنار ساعت

در PowerShell، از پوشهٔ ابزار اجرا کنید:

```powershell
.\ChatGPT-Switcher.cmd -Setup
```

این دستور یک میان‌بر **Codex Account Switcher** روی دسکتاپ و دو میان‌بر در منوی Start می‌سازد. میان‌بر **Codex Account Switcher** انتخاب‌گر حساب و **Codex Switcher (tray)** حالت tray را باز می‌کند. نام ابزار را در Start جست‌وجو کنید. در صورت پشتیبانی ویندوز می‌توانید میان‌بر را به نوار وظیفه سنجاق کنید.

```powershell
.\ChatGPT-Switcher.cmd -Tray
.\ChatGPT-Switcher.cmd -AutoStartTray
.\ChatGPT-Switcher.cmd -NoAutoStartTray
```

دستور اول حالت tray را اجرا می‌کند. کلیک چپ روی آیکون، انتخاب‌گر حساب را باز می‌کند و راست‌کلیک، فهرست حساب‌ها و گزینهٔ خروج را نشان می‌دهد. اگر آیکون را نمی‌بینید، بخش آیکون‌های مخفی کنار ساعت را بررسی کنید. برای هر کاربر ویندوز فقط یک نمونهٔ tray اجرا می‌شود.

`-AutoStartTray` اجرای tray هنگام ورود به ویندوز را فعال و `-NoAutoStartTray` آن را غیرفعال می‌کند. این تنظیم از منوی Settings هم قابل تغییر است. غیرفعال‌کردن اجرای خودکار، نمونهٔ در حال اجرا را نمی‌بندد؛ برای آن **Exit tray mode** را بزنید.

اگر پوشهٔ ابزار را جابه‌جا کردید، `-Setup` را دوباره اجرا و میان‌برهای حساب‌ها را بازسازی کنید. برای اصلاح مسیر اجرای خودکار هم `-AutoStartTray` را دوباره اجرا کنید.

## دستورهای پرکاربرد

دستورها را از پوشهٔ ابزار اجرا کنید. نام دارای فاصله را داخل کوتیشن قرار دهید. شناسهٔ ثابت حساب نیز به‌جای نام قابل استفاده است؛ `-List` آن را نشان می‌دهد.

برای نام‌های دارای نویسه‌های خاص CMD، مانند `&`، `|`، `<`، `>`، `^`، `%`، `!` یا پرانتز، فایل `.ps1` را مستقیم اجرا کنید. کوتیشن به‌تنهایی این نام‌ها را در اجرای `.cmd` ایمن نمی‌کند:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ChatGPT-Switcher.ps1 -Add 'Work & Personal'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ChatGPT-Switcher.ps1 -Launch 'Work & Personal'
```

در اسکریپت‌های خودکار که نام را از ورودی کاربر می‌گیرند، برای افزودن و اجرای پروفایل، `.ps1` را مستقیم صدا بزنید. نام را به‌عنوان پارامتر بدهید و از آن رشتهٔ دستور نسازید.

```powershell
.\ChatGPT-Switcher.cmd -Add Work
.\ChatGPT-Switcher.cmd -Add "Personal account" -NoShortcut
.\ChatGPT-Switcher.cmd -Launch Work
.\ChatGPT-Switcher.cmd -Launch __main__
.\ChatGPT-Switcher.cmd -List
.\ChatGPT-Switcher.cmd -Diagnose
.\ChatGPT-Switcher.cmd -Version
```

عملیات خط فرمان نتیجه را در همان ترمینال چاپ می‌کنند و کد خروج `0` برای موفقیت و `1` برای خطا برمی‌گردانند. اجرای انتخاب‌گر و tray جدا انجام می‌شود.

با `-Add`، گزینهٔ `-NoShortcut` از ساخت میان‌بر حساب جلوگیری می‌کند. ترکیب `-Setup -NoShortcut` همچنان همهٔ میان‌برهای Setup را می‌سازد و فقط پنجرهٔ اعلام پایان را نشان نمی‌دهد. این تفاوت نام‌گذاری برای سازگاری قدیمی حفظ شده است.

### حذف حساب و حفظ داده

```powershell
.\ChatGPT-Switcher.cmd -Remove Work -KeepData
```

این دستور ثبت حساب و میان‌بر آن را حذف می‌کند و پوشهٔ داده را نگه می‌دارد. افزودن دوبارهٔ همان نام، پروفایل تازه می‌سازد؛ پوشهٔ قبلی خودکار بازیابی نمی‌شود و فرمان import یا restore وجود ندارد.

**دستور `-Remove Work` بدون `-KeepData` داده‌های محلی پروفایل، شامل اطلاعات ورود، تنظیمات و پروژه‌ها/گفت‌وگوهای محلی تحت مدیریت برنامه را برای همیشه حذف می‌کند.** حساب آنلاین حذف نمی‌شود. خط فرمان قبل از حذف تأیید نمی‌خواهد؛ رابط گرافیکی تأیید می‌خواهد. بازگردانی داخلی وجود ندارد و `accounts.json.bak` فقط نسخهٔ قبلی فهرست حساب‌هاست، نه پشتیبان داده‌های پروفایل. Main با این دستورها حذف نمی‌شود.

## محل داده‌ها و محدودیت جداسازی

داده‌های پروفایل‌ها در این مسیر ذخیره می‌شوند:

```text
%USERPROFILE%\ChatGPT-Accounts\
  accounts.json
  accounts.json.bak
  accounts.lock
  switcher.log
  <profile-id>\
    electron\
    codex\
```

ابزار برای هر اجرا، مسیر دادهٔ Electron و `CODEX_HOME` جدا تنظیم می‌کند. فایل `auth.json`، کوکی یا توکن را نمی‌خواند، کپی نمی‌کند و جابه‌جا نمی‌کند. ورود فقط داخل برنامهٔ رسمی انجام می‌شود.

همهٔ پروفایل‌ها همچنان با یک کاربر ویندوز اجرا می‌شوند. فایل‌های پروژه‌ای که عمداً از یک پوشهٔ مشترک باز می‌کنید، مشترک می‌مانند. این روش، sandbox یا مرز امنیتی میان حساب‌های نامطمئن نیست و رمزنگاری اضافه ندارد.

اجرای فرایندها و پوشه‌های جدا با نسخهٔ Store **26.1023.6621.0** آزمایش شده است. هویت دو ورود واقعی و ماندگاری آن‌ها پس از راه‌اندازی مجدد هنوز کامل تأیید نشده است. پیش از کار حساس، هویت نمایش‌داده‌شده در هر پنجره را بررسی کنید. تغییر نسخهٔ برنامه ممکن است سازگاری را تحت تأثیر قرار دهد.

## به‌روزرسانی و رفع مشکل

برای به‌روزرسانی، از tray خارج شوید و انتخاب‌گر را ببندید. فایل‌های نسخهٔ جدید را در همان پوشه جایگزین کنید یا در clone تمیز، `git pull` بزنید. سپس `-Version` و `-Setup` را اجرا کنید. اگر اجرای خودکار فعال بوده، `-AutoStartTray` را هم دوباره اجرا کنید. داده‌ها خارج از پوشهٔ برنامه هستند و خودکار منتقل یا حذف نمی‌شوند.

حالت قدیمی shared-auth از نسخهٔ ۱.۳.۰ حذف شده است. برای ورودی‌های قدیمی shared، پروفایل جدا بسازید و دوباره وارد شوید. فایل‌ها و پشتیبان‌های احراز هویت قدیمی خودکار خوانده، منتقل یا پاک نمی‌شوند و باید محرمانه نگه داشته شوند.

- اگر برنامه پیدا نمی‌شود، ابتدا آن را عادی باز کنید و سپس `-Diagnose` را اجرا کنید. مسیرهای نصب سفارشی ممکن است شناسایی نشوند.
- اگر حساب اشتباه باز می‌شود، انتخاب Main یا ورودی shared قدیمی را بررسی کنید. نسخهٔ برنامه و خطا را ثبت کنید و هویت داخل پنجره را بررسی کنید.
- اگر نشانگر Running قدیمی است، Refresh یا F5 را بزنید؛ منوی tray را دوباره باز کنید.
- اگر خطای قفل دارید، منتظر پایان عملیات دیگر بمانید و دوباره تلاش کنید. وجود فایل `accounts.lock` به‌تنهایی نشانهٔ قفل فعال نیست.
- اگر تنظیمات خراب شده، از ابزار خارج شوید و پس از نگه‌داشتن فایل خراب، یک `accounts.json.bak` معتبر را بازیابی کنید. این کار دادهٔ حذف‌شده را برنمی‌گرداند.
- اگر ویندوز اجرا را مسدود کرده، ابتدا منبع را بررسی کنید. فقط در صورت اعتماد، از Properties > Unblock استفاده کنید. سیاست سازمانی ممکن است اجازهٔ اجرا ندهد.

برای گزارش مشکل در [Issues](https://github.com/AliNajafpour/chatgpt-switcher/issues)، نسخهٔ ویندوز، PowerShell و برنامه، مراحل تکرار مشکل و متن خطا را بفرستید. خروجی تشخیص و `switcher.log` ممکن است نام کاربری ویندوز، مسیرها، نام پروفایل و خط فرمان فرایندها را نشان دهند. پیش از انتشار، آن‌ها را دستی بازبینی و اطلاعات شخصی را حذف کنید. پوشهٔ پروفایل، `auth.json`، کوکی، توکن یا پشتیبان ورود را ارسال نکنید.

## حذف ابزار

ابتدا `-NoAutoStartTray` را اجرا کنید و از tray خارج شوید. پوشهٔ ابزار، میان‌برهای دسکتاپ، Start و میان‌برهای سنجاق‌شده را حذف کنید. اگر می‌خواهید داده‌ها بمانند، پوشهٔ `%USERPROFILE%\ChatGPT-Accounts` را نگه دارید. حذف آن پوشه، پس از بستن همهٔ پنجره‌های پروفایل، تمام داده‌های محلی ذخیره‌شده در آن را پاک می‌کند.

حذف ابزار، برنامهٔ رسمی Codex یا داده‌های پیش‌فرض Main را حذف نمی‌کند. سرویس نصب‌شده یا به‌روزرسان خودکار وجود ندارد.

## امنیت، بررسی‌ها و مجوز

خود switcher هیچ درخواست شبکه‌ای یا telemetry ندارد. برنامهٔ رسمی برای ورود و استفادهٔ عادی به شبکه نیاز دارد. حفاظت داده‌ها به مجوزهای ویندوز و ذخیره‌سازی برنامه وابسته است. جزئیات محدودیت‌ها در [بررسی امنیتی](SECURITY-REVIEW.md) و [گزارش بررسی](REVIEW.md) آمده است.

برای مشارکت، [CONTRIBUTING.md](CONTRIBUTING.md) و بخش Development در [راهنمای انگلیسی](README.md#development-and-checks) را بخوانید. بررسی‌های `self-check.ps1`، `cli-self-check.ps1` و `ui-self-check.ps1` با Windows PowerShell 5.1 و PowerShell 7 اجرا می‌شوند؛ جای آزمون ورود واقعی را نمی‌گیرند.
